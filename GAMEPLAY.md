# Core gameplay loop

1. Fortress — briefing, upgrades, class, mods
2. Lattice Wilds — hybrid maps, dynamic Corruption, glitch storms
3. Fight / scan / purify
4. Objectives — rescue, towers, outposts, elites
5. Extract — level, gear, next drop

# Classes x First Circle

- Eco-Blade Sentinel = Ash / Rowan Vale
- Vanguard Defender = Keep / Dace Morrow
- Cipher Ranger = Briar / Lira Moss
- Tech Warden = Trace / Ivy Quill

Abilities: Shield Pulse, Scan Burst, Purify Field, class Ultimate.

# Enemy behavior

- Glitch Wolves rush in packs
- Code Reapers teleport and flank
- Fractured Sentinels fire glitch beams
- Bosses corrupt the environment mid-battle

# Modes

- Campaign — story
- Strike Ops — short co-op
- Fortress Defense — waves on HQ
- Open-Zone Exploration — free roam

# Pitch line

You fight through corrupted forest-cyber zones, complete missions, purify areas, upgrade your Defender, and protect the HavenShield Fortress from a growing digital threat.
