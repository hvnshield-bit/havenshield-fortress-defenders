# HavenShield Fortress Defenders

Public, free cybersecurity training game from HavenShield.

Playable in any browser. Progress stays on the device.

Players defend a digital fortress by completing short missions across the 8 Shields of Digital Safety:

1. Passwords
2. 2-Step Verification
3. Wi-Fi
4. Devices
5. Scam Awareness
6. Backups
7. Safe Browsing
8. Kids Online

## Local preview

Open `index.html` or serve the folder:

```bash
python3 -m http.server 8080
```
