# HavenShield Fortress Defenders — Controls

## Console (Xbox / PlayStation)

Movement: Left stick move, Right stick aim, L3 sprint, R3 melee.
Combat: RT/R2 fire, LT/L2 ADS, RB/R1 secondary/gadget, LB/L1 class ability.
Eco-tech: Y/△ swap, X/□ reload, B/○ dodge, A/✕ jump, hold A Eco-Boost.
Systems: D-pad ↑ Scan Burst, ↓ Purify Field, ← ping, → tactical.
Ultimate: LB+RB / L1+R1.
View = briefing. Menu = inventory / armor / settings.

## Mobile HUD

- Left virtual stick — move
- Right-screen drag — aim
- Right fire — primary
- Secondary fire — gadget
- Reload / weapon swap buttons
- Ability 1 — class ability
- Ability 2 — Shield Pulse
- Ultimate — charges over time
- Jump / double-tap jump Eco-Boost
- Swipe down — dodge / slide
- Scan / Purify / Ping buttons
- Top left — map / mission
- Top right — inventory / armor
- Pause — settings

## Advanced (all platforms)

- Hold aim + melee — Charged Eco-Blade
- Jump + aim down — Aerial Precision Shot
- Sprint + slide — Corruption-Breaker Slide
- Scan + fire — auto-tag corrupted enemies
