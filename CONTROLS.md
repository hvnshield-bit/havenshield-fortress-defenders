# HavenShield Fortress Defenders — Controller map

Xbox / PlayStation.

## Movement
- Left stick — Move
- Right stick — Aim
- L3 — Sprint
- R3 — Melee

## Combat
- RT / R2 — Fire primary
- LT / L2 — ADS
- RB / R1 — Secondary / gadget
- LB / L1 — Class ability (Shield Pulse, drone, etc.)

## Eco-tech
- Y / Triangle — Switch weapons
- X / Square — Reload
- B / Circle — Dodge / roll
- A / Cross — Jump
- A hold — Double jump (Eco-Boost)

## Systems
- D-pad Up — Scan Burst
- D-pad Down — Purify Field
- D-pad Left — Ping / team marker
- D-pad Right — Tactical menu
- LB+RB / L1+R1 — Ultimate
- View / Touchpad — Mission briefing
- Menu / Options — Inventory, armor, settings
